# Explainable Multimodal Interview Analysis for Speech and Body Language Recognition

## Overview
This project explores multimodal analysis of speech and body-language features using deep learning techniques.

## Main Components
- Speech emotion recognition using CNN and Wav2Vec 2.0
- Body-language feature analysis
- Temporal alignment of audio and video features
- Bidirectional cross-modal attention
- Gated Multimodal Unit (GMU) for feature fusion

## Technologies
- Python
- PyTorch
- Deep Learning
- Audio and Video Processing

## Dataset

The study uses the IEMOCAP dataset for speech analysis and a body-language video collection comprising AI-generated clips and videos collected from external sources. Permission was sought from the respective content authors for the use of externally sourced body-language videos. The use and redistribution of these videos remain subject to the permissions granted and the applicable source terms.
